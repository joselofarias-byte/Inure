# Fork identity

- Maintainer / distribution brand: **JoseloFarias**
- Application: **Inure**
- Android application ID (JoseloFarias flavor): `app.simple.inure.joselofarias`
- GitHub account suffix `-byte` is not part of the product brand.
- Fork-specific UI, release metadata and documentation must identify **JoseloFarias** consistently.

## Package identity

The `joselofarias` product flavor appends `.joselofarias` to the inherited base application ID, producing `app.simple.inure.joselofarias`. This already keeps the distributed fork distinct from upstream without forcing a namespace migration.
